Chapter 01

Getting Started & Project Setup

Story Builder Studio organizes your creative work into self-contained folders so your scripts, concept art, dialogue tracks, and video clips stay together. When you first launch the app, two setup dialogs guide you into an active workspace.

Setup Flow Screens Click any screen to enlarge

First-Run Setup Wizard

Settings → Re-run Wizard

Walks you through choosing between Remote REST APIs (like Gemini or OpenAI) and optional local AI model folders. You can reopen this wizard anytime from the Settings panel.

Series Launcher Modal

File → Open / New Series

Appears whenever no Series folder is loaded. Pick a previously opened Series from your recent list, browse to an existing folder, or create a new Series directory.

How Series & Episodes Fit Together

A Series is your top-level production folder (holding shared lore, series-wide prompt templates, and episode folders). Each Episode inside that Series is an active project with its own scripts/, assets/images/, assets/audio/, assets/video/, and audit logs.

Chapter 02

Main Window, Header & Master Tabs

Once a Series and Episode are open, the main window unlocks six workspace tabs across the top bar. Each tab switches the center canvas while keeping your active project and engine drivers synchronized.

Top Bar & Workspace Tab Controls Always Visible
Episode Status & API Pill Displays the active Episode name on the left and the currently active Script engine on the right.
📁 Project Details Manage Series metadata, Episode info, and create or switch between Episodes in the current Series.
🎬 Storyboard Arrange shots in sequence, assign generated keyframes, and structure timeline beats for your episode.
📝 Script · 🖼️ Images · 🔊 Audio · 🎞️ Video Modality workspaces. The small colored dot next to each tab label indicates engine readiness (Cyan = ready/loaded, Red = unloaded).

Project Details Tab

Contains three stacked cards: Series Header, Project Details (episode configuration), and Episode List (add or load episodes). The top two cards start collapsed so your episodes stay immediately visible—click ▾ Details / ▴ Hide on either card to expand or collapse its metadata fields.

Storyboard Tab & Deck Export

Build shot cards, attach keyframes, link scripts, audio, and video clips, and reorder scenes. Once shots are populated, click Export PDF... or Export PPTX... in the top toolbar to generate a 16:9 widescreen page with a title slide followed by one shot per slide/page (keyframe, script excerpt, and linked assets).

Chapter 03

The Prompt Composer (Shared Controls)

The Script, Images, Audio, and Video tabs share a split workspace: your editor or media viewer sits on one side, and the Prompt Composer sits on the other. Learning these controls once lets you drive every AI modality.

Prompt Composer States Click either view to enlarge

Upper Pane: Engine & Output Stream

Engine & Model

Selects which backend handles the current tab (e.g., Gemini REST vs. local llama.cpp) and which specific weights file to initialize.

Load / Unload

Initializes the selected driver into memory. Click Unload when switching heavy local models (like FLUX to Wan Video) to free RAM/VRAM.

⚡ Specs & Profiler

Opens an estimator showing projected generation time, model footprint, and step/token metrics before you run a job.

Response Output Well

Streams live text tokens or displays status logs and saved file paths for media generations.

Lower Pane: Prompting, Options & Dispatch

Prompt Text

Switches the lower box to the main prompt editor and attachment tray.

⚙ Model Options

Switches the lower box to modality-specific parameters (such as temperature, image resolution/steps, TTS voice speaker, or video frame count).

▼ Prompts & ✏ Edit Prompts

Toggles a drawer of reusable .prompt style/camera plates that append automatically when checked, or opens the editor to create your own.

📜 History

Opens past prompts filtered to the active tab (showing saved asset filenames) so you can click any previous prompt to reload and iterate on it.

📎 Attach File(s)

Attaches context files scoped to the active tab—such as lore notes for Script, a reference frame for Image-to-Video, or a script file for Speech narration.

Submit Prompt

Opens the Confirm Outgoing Dispatch Preview modal so you can inspect the exact combined prompt and options before execution.

Chapter 04

Modality Workspaces & Media Controls

Each modality tab pairs the Prompt Composer with a specialized workspace built for editing, previewing, and curating that media type.

Script Workspace

saves to: scripts/

A full screenplay and markdown editor with Raw Edit, Markdown, and HTML preview modes, a live word/line counter, and built-in Find & Replace (Ctrl+F / Ctrl+H).

Cross-Tab Hand-Off: Highlight any scene description or line of dialogue in the editor, right-click, and choose Send To Prompt... to jump straight to the Image, Audio, or Video tab with that text pre-filled.

Images Workspace & Candidate Picker

saves to: assets/images/

When an image batch finishes generating, the Generated Image Candidates modal opens with a 2×2 preview grid:

  • Pick the Best Candidate: Click any thumbnail to highlight it as your single best pick (or hold Ctrl + Click to keep multiple variations).
  • Save or Assign: Click ✔ Save Best Image to save into your project gallery, ✔ To Shot to assign directly to a Storyboard shot, or ✕ Discard All to reject the batch.

Audio Workspace & Waveform Player

saves to: assets/audio/

Supports both Speech Narration (Kokoro TTS) and Sound Effects / BGM (audio.cpp). Newly generated .wav files automatically refresh the project audio library and load into the interactive waveform viewer for immediate scrubbing and playback.

Video Workspace & Timeline Scrubber

saves to: assets/video/

Generate clips from a text prompt (Text-to-Video) or attach a saved keyframe from assets/images/ to animate a still frame (Image-to-Video). Completed .mp4 clips load automatically into the video viewport with timeline scrubbing controls.

Chapter 05

History Inspector & Application Settings

Every generation across your project is recorded automatically so you never lose track of which prompt, options, or engine produced a specific asset.

Prompt & Thought History Inspector

Open from the top menu bar to browse a chronological log of all generations across every modality. Switch between Response / Output, Reasoning / Think, and Combined views, or right-click any pane to copy text.

Settings Control Panel

Configure your model base directory, verify remote API key status, adjust editor font size, switch UI themes, or re-launch the First-Run Setup Wizard.

End-to-End Production Flow

How your workspace tabs pass assets and prompts from initial draft to finished storyboard:

1
Project Details: Open a Series and create or select an Episode folder.
2
Script Tab: Draft scenes, then right-click any passage → Send To Prompt... to seed visual or audio prompts.
3
Images & Audio Tabs: Pick the best candidate frame (assets/images/) and narrate dialogue or SFX (assets/audio/).
4
Video Tab: Attach a saved image keyframe to animate an Image-to-Video clip (assets/video/).
5
Storyboard Tab: Sequence your shots, assign keyframes, and review the full episode flow.
